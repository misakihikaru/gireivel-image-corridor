# 異端蒐集館 — 第一蒐集「例外の所在」

既存の静的な GIREIVEL MANOR に加わる第五の部屋。依存ライブラリ・API・外部送信を使わず、ブラウザだけで動く日本語の短編遊戯。

## 一巡

1. 入口：任意の一文を預ける。自由記述は解析しない。
2. クロノアの幸福都市：五つの裁定と結果。最後の憲章で三つの結末に分かれる。過去の配給・帰還条項は残り、退出制限は最終憲章に従う。
3. ヴェルの反転劇場：同じ判決を裁定者・申請者・残る者から読む。最後に裁定を維持または再考する。初めの裁定は上書きしない。
4. ラクスの解体机：三つの前提を採否し、条件付きの論証を確かめる。費用の反論は未合意の負担という前提を外す。自由記述による異議はそのまま保存する。
5. レゼルの変容書庫：ブラウザへの明示的な収蔵、全文テキストの持ち出し、後日の追記、確認付き削除。収蔵数で書庫の背表紙が増える。

## ファイル

- `index.html`：入口、共通ナビゲーション、ダイアログ。
- `styles.css`：黒・白・赤の造形、各部屋の装丁、モバイル表示、キーボードフォーカス。
- `core.mjs`：物語、裁定、前提、保存データ検証、記録の書き出し。DOM に依存しない。
- `app.mjs`：表示、進行、ブラウザ保存、ダイアログ、持ち出し。
- `tests/`：243経路・再開・論証・記録保全のテスト。DOMテストは実ブラウザの描画検証を含まない。

## 保存

`localStorage` の独立キー `gireivel.heresy.v1` を使用。既存の観測室の記録には触れない。進行中の一巡を自動保存し、完了した記録は本人が収蔵を選んだ場合に保存する。上限は30件、各記録への追記は100件。上限到達時に古い記録を自動削除しない。保存が利用できない場合は画面に知らせ、遊戯とテキスト持ち出しを利用できる。端末間同期はない。

## 確認

```powershell
python -m http.server 8765 --bind 127.0.0.1
node --test heresy-collection/tests/core.test.mjs
```

DOMテストのみ、サイト外の検証用フォルダへ `jsdom` を用意する（サイト配信には不要）。

```powershell
$env:NODE_OPTIONS='--use-system-ca'
npm.cmd install --prefix "$env:TEMP\gireivel-validation" --no-save --ignore-scripts jsdom
$env:GIREIVEL_TEST_DEPS="$env:TEMP\gireivel-validation\node_modules"
node --test heresy-collection/tests/*.test.mjs
```

公開は既存の GitHub Pages の手順を使う。新しいホスティングプロジェクトへの移行は不要。元の人物プロンプトや合言葉はサイトに含めない。
